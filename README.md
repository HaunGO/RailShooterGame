# Rail Shooter (web MVP)

Browser rail shooter prototype built with **Vite**, **Three.js**, and **GSAP**. See [docs/ProjectBrief.md](docs/ProjectBrief.md) and [docs/Status.md](docs/Status.md) for product context and current feature snapshot.

## Quick start

```bash
npm install
npm run dev
```

Dev server settings live in [vite.config.js](vite.config.js) (default local URL uses port **1001**).

```bash
npm run build    # static output in dist/
npm run preview  # local preview of production build
```
